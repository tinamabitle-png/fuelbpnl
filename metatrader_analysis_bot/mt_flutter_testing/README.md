# MT Flutter Testing (No Auth)

Flutter test app created inside the meta folder for Android and Web validation.

## Scope

- No login/authentication flow.
- Direct analysis dashboard on app launch.
- Simulated strategy outputs for testing UI/workflow.
- Language choices displayed in-app.

## Run

From this folder:

```bash
/Users/apple/development/flutter/bin/flutter pub get
/Users/apple/development/flutter/bin/flutter run -d chrome
/Users/apple/development/flutter/bin/flutter run -d android
```
