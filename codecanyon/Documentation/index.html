Server Requirements

  • PHP 8.2+
  • MySQL 8.0+ or MariaDB 10.6+
  • Composer 2.x
  • Node.js 20+ and npm 10+
  • Nginx or Apache with URL rewriting
  • SSL certificate for production

Installation

  1. Upload and extract Bwiser-Laravel-App-v1.0.0.zip.
  2. Run composer install --no-dev --optimize-autoloader.
  3. Run npm ci && npm run build.
  4. Copy .env.example to .env.
  5. Set database, app URL, and third-party keys in .env.
  6. Run php artisan key:generate.
  7. Run php artisan migrate --force.
  8. Run php artisan storage:link.
  9. Run php artisan config:cache && php artisan route:cache && php artisan view:cache.

Environment Keys

Configure only the providers you use:

  • Google Sign In: GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, GOOGLE_REDIRECT_URI
  • Google Maps: GOOGLE_MAPS_API_KEY
  • Paystack: PAYSTACK_PUBLIC_KEY, PAYSTACK_SECRET_KEY
  • OpenAI (optional): OPENAI_API_KEY

First Admin Account

  1. Create a user account via registration.
  2. Assign admin role via Tinker or SQL according to your deployment policy.
  3. Login and complete platform settings.
